Why MCPShield

MCP expands the blast radius of an AI agent. Security has to move with it.

Every MCP server can add code, capabilities and model-visible instructions to an agent session. MCPShield gives engineering and security teams a practical way to discover that surface, assess it, lock reviewed definitions and enforce policy at runtime.

01

Discover shadow MCP

Inventory configured MCP servers across supported clients and projects, including local and remote targets that may not be centrally tracked.

02

Assess trust before execution

Check configs, launchers, packages, permissions, secrets, remote endpoints and tool metadata before an agent depends on them.

03

Control runtime behavior

Put a policy guard between client and server to block risky calls, redact secrets, deny sampling and preserve an auditable record.

How it works

Start safe. Add depth only when you need it.

MCPShield is designed around a progressive workflow. Static discovery and configuration assessment come first. Live inspection and runtime controls are explicit steps—not hidden side effects.

Find MCP configurations and build an inventory.

2

Assess

Score config, package, endpoint and tool risks.

3

Pin

Lock reviewed tool definitions to detect changes.

4

Guard & observe

Enforce policy and trace real agent activity.

Trust through clarity

Strong controls without false certainty.

MCPShield is security tooling, not a magic boundary. The project documents what it can detect, where it can enforce policy and where platform isolation is still required.

Fail-closed hardening

Malformed protocol messages, invalid policy and incomplete pin verification are treated as security conditions rather than silently accepted.

Privacy-aware by default

Argument capture for audit and OTLP is opt-in, audit keys are isolated from child processes and static scans do not require a hosted service.

Known limitations are public

The runtime guard is defense in depth—not an OS sandbox. Hostile servers still belong behind container, process and network controls.
